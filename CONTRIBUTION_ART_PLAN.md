# GitHub Contribution Art Plan

## Locked target and honest display constraints

- Contribution-graph wordmark: **LOKESH PARGAIN**
- Full professional identity line: **LOKESH PARGAIN AI ENGINEER**
- Target review date: **December 2027**
- Visual direction: one continuous left-to-right wordmark; dark cells form letters and lighter cells are the surrounding field.

GitHub's contribution calendar is a rolling view of about 52 weeks by 7 weekdays. It is not a free-form canvas: each square represents one date, and its shade depends on GitHub's contribution-count buckets. A date cannot be assigned an arbitrary colour.

The compact 3×5 pixel lettering below is designed to fit **LOKESH PARGAIN** across 52 columns. The complete phrase **LOKESH PARGAIN AI ENGINEER** is too wide to remain legible as one horizontal line in a single 52-week calendar. It will therefore be used in the profile README/banner, while the contribution calendar carries the shorter name wordmark. This keeps the graph physically feasible without stacking text.

## 7-row × 52-column concept map

- `#` = target letter cell (higher genuine contribution activity)
- `.` = background cell (ordinary genuine contribution activity)
- The five glyph rows are vertically centered in the seven weekday rows.
- Columns run from left to right as weeks progress.

## Contribution rules

1. Keep daily work genuine: code, tests, documentation, bug fixes, refactoring, and useful project improvements.
2. On dates that map to `#`, prioritize a larger meaningful deliverable where naturally available. Do not manufacture empty commits, backdate activity, or split trivial edits just to manipulate shades.
3. On `.` dates, continue normal work. Never create low-value commits just to fill a square.
4. GitHub controls contribution thresholds and qualifying activity. The map is a design target, not a guarantee that a chosen commit count will produce a particular green shade.
5. The calendar rolls forward. We must refresh the date-to-cell mapping periodically; a one-time schedule cannot permanently pin letters to fixed screen positions.

## Automation status

This file records the design only. It does **not** change the daily workflow, create commits on a date schedule, or guarantee dark/light shades.
